# 🌟 Project Vision

## Vision Statement
To transform every university programming lab into an adaptive, high-engagement learning environment where no student is left stranded, cheating is replaced with guided discovery, and educators possess superpowers of real-time academic insight.

## Core Philosophical Pillars

1. **Socratic Over Solutionist**:
   - The AI must *never* write the code for the student.
   - It acts like a world-class senior tutor: asking leading questions, pinpointing cognitive misconceptions, and providing incremental clues.

2. **Empower, Don't Replace, Faculty**:
   - CodeMentor AI is an assistant to the professor, not an automated grading replacement.
   - It surfaces aggregate insights: *"80% of your class is stuck on index bounds in Problem 2."*

3. **Zero-Friction Access**:
   - No heavy local environment setups for students (Python installs, PATH issues, broken pip packages).
   - Runs 100% in the browser with Monaco Editor, cloud or client-side execution, and Google SSO.

4. **White-Label Readiness**:
   - Configurable in minutes for any college or university with custom branding, logo, and assignment configurations.
